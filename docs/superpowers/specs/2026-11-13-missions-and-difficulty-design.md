# 목표 있는 대화 + 난이도 자동 조절 — 설계 문서

작성일: 2026-11-13
상태: 초안 (사용자 승인 대기)
기반: `2026-11-13-english-speaking-app-design.md` (이미 배포된 앱에 기능 추가)

## 1. 목적과 이유

- 사용자 피드백: 같은 상황을 고르면 **매번 같은 대화**가 반복되고, **실력이 늘어도 난이도가 그대로**다.
- 대화가 너무 자유로운 수다가 되지 않도록, **구체적인 목표(미션)**가 있고 그 목표를 이루는 방향으로 대화가 흘러가길 원한다.
- 목표: 같은 상황이라도 매번 다른 목표와 전개가 나오고, 잘하면 점점 어려워지는 것.

## 2. 목표 / 비목표 / 실패 조건

**목표**
- 대화마다 이번 대화의 **목표 1~4개**를 보여주고 진행 상황을 체크한다.
- 상황별 **난이도 1~5단계**를 기록하고 결과에 따라 자동으로 올리거나 내린다.
- 목표는 AI가 매번 새로 만든다. 실패하면 미리 써 둔 예비 목표를 쓴다.
- 집 모드와 차 모드 모두 지원한다.

**비목표**
- 레벨 시험, 점수, 순위, 배지
- 사용자가 난이도를 직접 고르는 기능 (사용자가 A안 "자동"을 선택함)
- 목표 달성을 앱이 직접 판정하는 규칙 엔진 (판정은 AI 응답에 맡긴다)

**실패 조건**
- 차 모드에서 목표를 만들지 못해 **연습이 시작되지 않거나 멈추는 것** (예비 목표로 반드시 시작해야 함)
- 차 모드에서 목표를 보려면 화면을 봐야 하는 것 (소리로 알려야 함)
- 처음 쓰자마자 바로 나가면 난이도가 떨어지는 것처럼, **너무 짧은 대화로 난이도가 바뀌는 것**
- 비용이 생기는 것 (무료 등급 안에서)

## 3. 제약 조건

- 기존 제약 그대로: 아이폰 PWA, 0원, Gemini 무료 등급(`gemini-3.5-flash-lite` → `gemini-2.5-flash-lite` 순서로 시도), 한 사용자 턴당 API 호출 1번.
- 목표 생성은 **대화 하나당 추가 호출 1번**까지 허용한다 (사용자 동의: 3번 방법).
- 차 모드 시작 시 인터넷이 불안정할 수 있다.

## 4. 검토한 방법과 선택

| 방법 | 내용 | 장단점 |
|---|---|---|
| 1. AI가 매번 목표 생성 | 대화 시작 때 Gemini에 목표+첫 대사 요청 | 매번 새로움, 단계 맞춤 / 시작 1~3초, 끊기면 시작 불가 |
| 2. 미리 써 둔 목표 | 상황×단계별 목표 목록 | 즉시 시작 / 수백 개 작성, 반복됨 |
| **3. AI 생성 + 예비 목표 (선택)** | 기본은 1, 실패하면 상황별 예비 목표 1~2개 | 새로움 + 끊겨도 시작 / 조금 더 작업 |

사용자가 **3번**을 골랐다.

## 5. 정해진 사항

### 5.1 용어
- **난이도 단계(1~5)**: 이번 기능. 상황마다 따로 기록된다.
- **연습 방식(쓰고 말하기 / 힌트 보고 말하기 / 바로 말하기)**: 기존 집 모드 기능. 난이도와 별개다. 화면 문구에서 기존 "단계"라는 말이 난이도와 헷갈리지 않게, 집 모드 위쪽 선택 버튼 묶음 이름은 "연습 방식"으로 표시한다.

### 5.2 미션(목표) 구조
- 미션 = 제목(한국어, 짧게) + 목표 1~4개(각각 한국어 문장) + AI용 상황 설정(영어, 이번 전개/돌발 상황) + 첫 대사(영어) + 난이도 + 출처(AI/예비).
- 목표 개수는 단계에 따라: 1단계 1~2개, 2단계 2개, 3단계 2~3개, 4단계 3개, 5단계 3~4개.
- AI가 만들 때 **최근 미션 제목 5개**를 함께 보내서 겹치지 않게 한다.
- 자유 대화도 미션을 가진다 (예: "주말 계획 이야기하기: 계획 1가지 말하기, 상대에게 질문 2번 하기").

### 5.3 단계별 난이도 (AI 지시에 반영)

| 단계 | AI 말투 | 목표/상황 |
|---|---|---|
| 1 | 아주 짧고 쉬운 문장, 기본 어휘 | 단순한 요청 1~2개, 돌발 상황 없음 |
| 2 | 쉬운 문장, 질문 1개씩 | 요청 2개 |
| 3 | 보통 길이, 예상 못 한 질문 1번 | 작은 문제 상황 1개 (품절, 착오 등) |
| 4 | 자연스러운 문장, 관용 표현 일부 | 문제 해결이나 선택 설명 |
| 5 | 원어민에 가까운 속도와 표현, 말 돌려 하기 | 협상, 불만 처리, 이유 설명 |

- 음성 속도(목소리 빠르기)는 사용자 설정을 따르고 난이도로 바꾸지 않는다.

### 5.4 대화 중 진행
- 매 턴 AI 응답에 **이번 턴에 새로 달성한 목표 번호**가 들어온다. 앱이 누적해서 체크한다.
- AI 지시: 목표 쪽으로 자연스럽게 이끌되 **정답 문장을 대신 말해 주지 않는다**. 목표에서 벗어나면 상대역으로서 자연스럽게 되돌린다.
- **모든 목표를 이루면**: AI는 그 턴의 대사로 대화를 자연스럽게 마무리하고, 앱은 "목표 달성!"을 표시하거나 말한다.
- 기존 교정, 발음 피드백, 음성 명령, 힌트는 그대로 동작한다. 힌트(`suggestedReply`)는 남은 목표 쪽으로 향하는 문장으로 만든다.

### 5.5 난이도 자동 조절 규칙
- 대화(미션)가 끝날 때 한 번 평가한다.
  - **평가하는 끝**: 목표 모두 달성, "그만", "다음"(미션 포기), 대화 끝내기, 그만하고 홈으로, 화면 이동.
  - **평가하지 않는 끝** *(작성자가 정한 사항)*: 사용 한도·API 키·앱 설정 오류, 계속 못 알아들음, 일시정지 상태로 앱이 꺼짐. 앱이나 인터넷 문제로 난이도가 떨어지면 안 되기 때문이다.
- **사용자 턴**은 받아 적은 말이 있고 음성 명령이 아닌 턴만 센다("다시", "힌트", "목표" 등은 제외) *(작성자가 정한 사항)*.
- 목표를 다 이루지 못한 경우는 **사용자 턴이 2개 미만이면 평가하지 않는다.** 목표를 모두 이룬 경우는 턴 수와 상관없이 평가한다 *(작성자가 정한 사항: 1단계는 목표가 하나라 한 턴에 끝날 수 있음)*.
- 목표를 **모두 달성** + 교정 수가 사용자 턴 수의 1/3 이하 → **한 단계 올림** (최대 5), 실패 횟수 0으로.
- 목표를 모두 달성했지만 교정이 많음 → 그대로, 실패 횟수 0으로.
- 목표를 **다 이루지 못하고** 끝남 → 실패 횟수 +1. **2번 연속**이면 한 단계 내림 (최소 1), 실패 횟수 0으로.
- 일시정지(이어하기 가능)는 끝난 것으로 보지 않는다.
- 단계가 바뀌면 알린다: "3단계로 올라갔어요!" / "2단계로 낮췄어요. 천천히 다시 해 봐요."

### 5.6 집 모드 화면
- 헤더 아래에 **목표 카드**: 미션 제목, "N단계" 표시, 목표 목록(☐/☑).
- 목표 생성 중에는 "이번 목표를 준비하고 있어요…"를 보여주고 말하기 버튼을 잠근다.
- 목표 달성 시: 축하 문구 + 기존 교정 요약 화면. 요약 화면에 미션 제목, 달성 여부, 단계 변화를 함께 보여준다. "다음 목표" 버튼으로 같은 상황의 새 미션을 시작한다.

### 5.7 차 모드
- 시작하면 먼저 목표를 만들고(최대 대기는 기존 요청 제한 시간), **한국어로 목표를 읽어준 뒤** 영어 첫 대사로 시작한다.
- 새 음성 명령 **"목표"**: 남은 목표를 한국어로 다시 읽어준다 (추가 API 호출 없이, 명령 감지는 기존 턴 응답에 포함).
- 목표를 하나 이룰 때마다 짧게 "목표 하나 달성!"이라고 말한다(한국어).
- 모두 이루면: "목표 달성!" → (단계 변화가 있으면 알림) → **같은 상황의 새 미션으로 자동으로 이어간다**.
- 음성 명령 변경 *(작성자가 정한 사항)*:
  - **"다음"**: 지금 미션을 포기하고 **같은 상황의 새 미션**으로 간다 (미달성으로 평가). 집 모드도 같다.
  - **"다른 상황"** (새 명령): 지금 미션을 포기하고 같은 카테고리의 다음 상황으로 간다 (기존 "다음"의 동작). 평가는 원래 상황의 난이도에 반영한다.
- 이어하기(일시정지 후)는 같은 미션과 진행 상황을 유지한다.

### 5.8 예비 목표
- 상황마다 단계와 상관없는 간단한 예비 미션을 **1~2개** 앱에 넣어 둔다. 첫 대사는 상황의 기존 첫 대사를 쓴다.
- 미션 생성이 실패하면(인터넷 끊김, 시간 초과, 사용 한도, 이상한 응답) 예비 미션 중 하나로 **바로** 시작한다. 차 모드는 실패했다고 말하지 않는다.
- 예비 미션으로 한 대화도 난이도 평가에 포함한다.

### 5.9 저장
- 상황별 진행 정보(현재 단계, 연속 실패 횟수, 최근 미션 제목 5개)를 저장한다.
- **미션 하나 = 대화 기록(세션) 하나** *(작성자가 정한 사항)*. 차 모드에서 다음 미션으로 넘어가면 새 세션이 시작된다. 세션에 미션 제목, 목표 목록, 난이도, 목표 달성 여부를 함께 저장하고, 복습 화면에 보여준다.
- 백업 내보내기/가져오기에 진행 정보를 포함한다. 진행 정보가 없는 예전 백업 파일도 가져올 수 있어야 한다.
- 홈 화면 상황 카드에 현재 단계("3단계")를 표시한다.

## 6. 위험 요소
- AI가 목표 달성을 너무 쉽게 혹은 너무 늦게 판정할 수 있다 → 실제 사용 후 프롬프트 조정.
- 무료 한도: 대화당 요청 1번 추가. 짧은 대화를 많이 하면 한도에 조금 더 빨리 닿는다.

## 7. 만드는 사람에게 맡기는 것
- 미션 생성 요청과 응답의 JSON 구조, 프롬프트 문구
- 저장 방식 (새 저장소 추가 또는 기존 구조 확장, 백업 형식 버전 처리)
- 예비 목표의 구체적인 문구
- 목표 카드의 시각 디자인

## 8. 추가 변경 (2026-11-13, 사용자 승인): 상황극을 살리고 여러 번 주고받기

사용자 피드백: 상황극 없이 한두 마디 만에 목표가 끝난다. 아래 세 가지를 모두 적용한다.

1. **목표 설계**: 미션 생성 시 목표는 한 문장으로 끝나지 않고 여러 번 주고받아야 이룰 수 있게 만든다(상대가 묻는 세부 사항에 답하기, 정보 알아내기, 문제 해결). 상대역에게는 물어봐야 알려주는 숨겨진 정보와(3단계 이상) 돌발 상황을 준다.
2. **상황극 지시**: AI는 실제 직원·동료처럼 인사, 되묻기, 확인 질문을 섞는다. 한 턴에 목표 하나만 다루고, 목표는 대화 안에서 실제로 해결됐을 때만 달성으로 표시한다. 정해진 최소 횟수 전에는 대화를 마무리하지 않는다.
3. **최소 주고받기(앱이 강제)**: 단계별 최소 사용자 턴 수 — 1단계 3, 2단계 4, 3단계 5, 4단계 6, 5단계 7. 목표를 모두 이뤄도 최소 턴 수 전에는 대화를 이어가고, "목표 달성!"과 다음 미션 전환은 **목표 모두 달성 + 최소 턴 수 충족** 시점에 한다.
   - 난이도 평가의 "달성" 판정은 목표를 모두 이뤘는지로만 본다(중간에 그만두거나 나가도 목표를 다 이뤘으면 달성).
